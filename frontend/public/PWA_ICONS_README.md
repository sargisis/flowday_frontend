# PWA Icons Setup

Для работы PWA нужны иконки приложения. Плагин настроен на использование следующих файлов:

- `/public/pwa-192x192.png` - иконка 192x192px
- `/public/pwa-512x512.png` - иконка 512x512px

## Текущий статус

⚠️ **Иконки еще не созданы** - используйте временные или создайте собственные.

## Как создать иконки

### Вариант 1: Использовать существующий логотип
Если у вас есть логотип Flowday:
1. Откройте его в графическом редакторе (Figma, Photoshop, etc.)
2. Экспортируйте в PNG формате:
   - 192x192px → `pwa-192x192.png`
   - 512x512px → `pwa-512x512.png`
3. Поместите файлы в `/public/` директорию

### Вариант 2: Использовать онлайн генераторы
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- https://favicon.io/

### Вариант 3: Создать простые иконки
Можно создать простые SVG иконки и экспортировать их в PNG.

## Требования к иконкам

- **Формат:** PNG с прозрачным фоном (рекомендуется)
- **Размеры:** 
  - 192x192px (минимум)
  - 512x512px (рекомендуется)
- **Стиль:** Должен соответствовать бренду Flowday (темная тема, indigo цвет #6366f1)
- **Содержимое:** Логотип или иконка Hexagon (как в приложении)

## После создания иконок

1. Поместите файлы в `/public/` директорию
2. Пересоберите приложение: `npm run build`
3. PWA будет работать с новыми иконками

---

**Примечание:** Плагин `vite-plugin-pwa` автоматически:
- Создаст `manifest.webmanifest`
- Сгенерирует Service Worker
- Добавит иконки в manifest

Вам нужно только создать сами изображения иконок.
