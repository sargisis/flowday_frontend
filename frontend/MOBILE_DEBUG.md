# 🔍 Отладка мобильной версии

## Проблема: Белый экран на телефоне

### Шаг 1: Проверьте консоль браузера

**На телефоне (Chrome Android):**
1. Подключите телефон по USB к компьютеру
2. Включите "USB Debugging" в настройках разработчика
3. Откройте Chrome на компьютере
4. Перейдите на `chrome://inspect`
5. Найдите ваш телефон и нажмите "inspect"
6. Откройте вкладку "Console" и посмотрите ошибки

**На телефоне (Safari iPhone):**
1. На iPhone: Settings → Safari → Advanced → Web Inspector (ON)
2. На Mac: Откройте Safari → Develop → [Ваш iPhone] → [Страница]
3. Посмотрите консоль на ошибки

### Шаг 2: Проверьте доступность Backend

Backend должен быть доступен из сети на порту 8080.

**Проверка на компьютере:**
```bash
# Проверьте, что backend слушает на всех интерфейсах
netstat -tuln | grep 8080
# Должно быть: 0.0.0.0:8080 или *:8080
# НЕ должно быть: 127.0.0.1:8080
```

**Если backend слушает только на localhost:**
- Нужно изменить конфигурацию backend, чтобы он слушал на `0.0.0.0:8080`
- Для Go: `server.Listen("0.0.0.0:8080")` вместо `server.Listen("127.0.0.1:8080")`

**Проверка доступности с телефона:**
- Откройте на телефоне: `http://192.168.1.14:8080/api/v1/health`
- Должен вернуться ответ (не ошибка подключения)

### Шаг 3: Проверьте Firewall

```bash
# Проверьте статус firewall
sudo ufw status

# Если активен, разрешите порты:
sudo ufw allow 5173  # Frontend
sudo ufw allow 8080  # Backend
```

### Шаг 4: Перезапустите dev сервер

После изменений в коде нужно перезапустить:
```bash
# Остановите сервер (Ctrl+C)
# Запустите снова:
cd /home/asus/Desktop/flowday_frontend/frontend
npm run dev
```

### Шаг 5: Проверьте логи

В консоли браузера (на телефоне) должны быть логи:
- `🔧 Flowday Dev Mode`
- `📍 Hostname: 192.168.1.14`
- `🔗 Auto-detected API URL for mobile: http://192.168.1.14:8080/api/v1`

Если этих логов нет - значит JavaScript не загружается.

### Шаг 6: Проверьте Network tab

В DevTools на телефоне:
1. Откройте вкладку "Network"
2. Обновите страницу
3. Проверьте, какие запросы загружаются
4. Если есть красные (failed) - посмотрите причину

### Частые проблемы:

1. **Backend недоступен:**
   - Backend не запущен
   - Backend слушает только на localhost
   - Firewall блокирует порт 8080

2. **CORS ошибки:**
   - Backend не разрешает запросы с IP адреса
   - Нужно добавить `192.168.1.14` в CORS whitelist

3. **JavaScript ошибки:**
   - Проверьте консоль на ошибки
   - Могут быть проблемы с загрузкой модулей

4. **Проблемы с роутингом:**
   - Проверьте, что все пути правильные
   - Может быть проблема с base URL

## Быстрая проверка:

1. Откройте на компьютере: `http://192.168.1.14:5173` - должно работать
2. Откройте на компьютере: `http://192.168.1.14:8080/api/v1/health` - должен вернуть ответ
3. Если оба работают - проблема в телефоне или сети
4. Если не работают - проблема в конфигурации сервера
