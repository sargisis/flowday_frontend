**Выполнено:**

**Измененные файлы:**
- `frontend/src/pages/LandingPage.tsx` - добавлена функция `prefetchRoute()` и обработчики `onMouseEnter`

**Результат:**
- Страницы login/register предзагружаются при наведении на кнопки
- Быстрее навигация (почти мгновенная)
- Лучший UX для пользователей

**Технические детали:**
```typescript
// Prefetch route module by dynamically importing it
const prefetchRoute = (path: string) => {
    if (path === '/app/v1/register') {
        import("../pages/Register");
    } else if (path === '/app/v1/login') {
        import("../pages/Login");
    }
};

// Автоматический prefetching после загрузки
useEffect(() => {
    const timer = setTimeout(() => {
        prefetchRoute('/app/v1/login');
        prefetchRoute('/app/v1/register');
    }, 2000);
    return () => clearTimeout(timer);
}, []);

// Prefetching при hover
<button
    onMouseEnter={() => prefetchRoute('/app/v1/register')}
    onClick={() => navigate('/app/v1/register')}
>
```
